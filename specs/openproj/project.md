# Project: A2AWrapper

## Metadata

- id: a2awrapper
- name: A2AWrapper
- status: PoC
- repository: https://github.com/cawa0505/a2a-wrapper

## Description

Rust sidecar turning unmodified CLI coding agents (aider, codex, opencode, rho,
zero) into A2A v1 protocol nodes over a custom stdio/UDS binding.

## Capabilities

- pty-supervision — PTY process supervision + VT100 grid view (applied)
- exec-adapter — headless one-shot execution (Engine A) + outcome classification (applied)
